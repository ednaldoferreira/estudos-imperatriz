# Portal de Estudos — Prefeitura de Imperatriz

Aplicação web estática (HTML5, CSS3 e JavaScript puro) para acompanhamento de estudos dos cargos **Agente de Trânsito** e **Guarda Municipal** (banca FSADU).

Compatível com GitHub Pages. Dados salvos no `localStorage` do navegador.

## Como usar

Abra `index.html` no navegador ou sirva a pasta:

```bash
npx serve .
```

## Abas

1. Dashboard com KPIs e gráficos (Chart.js)
2. Matriz e edital verticalizado pré-carregado
3. Gerador de cronograma e Pomodoro
4. Controle de questões FSADU
5. Caderno de erros e flashcards
6. Revisões espaçadas 24h / 7d / 30d
7. Simulados com nota de corte
8. Treinamento TAF

Use **Exportar Backup (JSON)** e **Importar Backup (JSON)** no topo para copiar seus dados entre dispositivos.
